# Demo discussion preparation

Start with the [shared demo checklist](discussion-guides/README.md), then each
team member should study the guide assigned to them:

| Owner | Requirement | Preparation guide |
|---|---|---|
| _Write name_ | 1 — scheduling | [Scheduling guide](discussion-guides/requirement-1-scheduling.md) |
| _Write name_ | 2 — paging | [Paging guide](discussion-guides/requirement-2-paging.md) |
| _Write name_ | 3 — MFS extents | [MFS extent guide](discussion-guides/requirement-3-mfs-extents.md) |

Each owner must be ready to give the 30-second explanation, point to the main
source functions, run the known test, explain one result, answer the listed
questions, and state the implementation limitations accurately.
